## Projetos em destaque

### [GameMatch](https://github.com/gustech020-prog/GameMatch)
Aplicacao web para descobrir jogos em formato de swipe, criar salas, comparar curtidas em grupo e compartilhar resultados.  
Stack: React, Vite, Firebase, RAWG API, Vercel.  
Demo: [gamematch-one.vercel.app](https://gamematch-one.vercel.app)

### [Gustech](https://github.com/gustech020-prog/Gustech)
E-commerce/games storefront com catalogo, carrinho, pedidos, favoritos, backend em Node.js e persistencia local/SQL.  
Stack: JavaScript, Express, SQLite/MySQL, Firebase, Docker opcional.

### ServeAI
Sistema de gestao para restaurantes com PDV, pedidos, cardapio online, caixa, relatorios, WhatsApp via Evolution API e robo de respostas automaticas.  
Stack: React, TypeScript, Electron, Supabase, Evolution API, Tailwind, Vitest.  
Repositorio privado por conter contexto de produto e operacao.

### AutoWap
Aplicativo desktop para atendimento, campanhas, CRM leve, biblioteca de midia, contatos e integracao com WhatsApp/Evolution API.  
Stack: Electron, React, TypeScript, Mantine, Express, Prisma, SQLite/PGlite.  
Repositorio privado por conter contexto comercial e assets internos.
